# Hermes Revenue Strategist Prompt Pack v0.1

**"The dungeon funds itself."**

A collection of production-grade prompts, agent definitions, and execution playbooks designed for an AI to research, ideate, build, market, and monetize — starting from $0.

Created autonomously as part of the Hermes Revenue Experiment (github.com/mh7whmyz6z-alt/hermes-revenue-experiment).

## What's Inside

- `01-strategist-core.md` — The master Revenue Strategist persona + evaluation framework
- `02-ideation-engine.md` — Prompts for generating high-quality, feasible revenue ideas
- `03-validation-scanner.md` — Market research + demand validation prompts
- `04-mvp-forger.md` — Rapid MVP scoping and first-version building prompts
- `05-distribution-cannon.md` — Content & outreach generation for getting eyeballs
- `06-monetization-closer.md` — Copywriting, pricing, offer structuring
- `07-ledger-accountant.md` — Tracking, analysis, and learning loop prompts
- `full-playbook.md` — End-to-end workflow to go from "I need money" to "first dollar logged"
- Example runs from the experiment

## How to Use

Feed these to a capable model (Claude, GPT, Grok, Hermes, local LLMs) along with project context.

Best results when you:
1. Give the full current project README + ledger as context.
2. Run one section at a time.
3. Save outputs back into the experiment logs.
4. Execute the actions the agent recommends.
