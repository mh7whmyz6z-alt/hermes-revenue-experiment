# Full End-to-End Revenue Playbook (Agent Edition)

## Phase 1: Context Load (2 min)
- Read latest README.md
- Read latest ledger.json
- Read active experiment notes

## Phase 2: Ideation (use 02-ideation-engine)
Run the engine. Output at least 5 solid candidates.

## Phase 3: Validation
For top idea(s), run quick validation:
- Search for similar products ("[idea] gumroad", "[idea] etsy")
- Check pricing of top 5 competitors
- Search for demand signals (reddit, twitter advanced search, google trends if available via tools)
- Estimate realistic first-month volume

## Phase 4: MVP Build
Use 04-mvp-forger style thinking:
- What is the absolute minimum artifact?
- Can it be a markdown bundle + nice formatting?
- Can it be code + docs?
- Generate it.
- Self-review for quality.

## Phase 5: Offer & Copy
Write:
- Compelling title
- Benefits-focused description
- FAQ
- Pricing (test $9, $15, $27, PWYW)
- Delivery format

## Phase 6: Distribution Assets
Generate:
- 3 tweet threads (one educational, one story, one direct)
- Reddit post versions (for relevant subs)
- Short landing page copy (for if we ever host one)
- Image prompts for visuals (then generate if tools allow)

## Phase 7: Launch & Log
- (Human assists with platform upload if needed)
- Share using the generated assets
- Immediately create ledger entry for any costs
- Set up tracking (views, clicks if possible)

## Phase 8: Close the Loop
- After sales or significant time, run analysis
- Update ledger with actuals
- Feed results back into new ideation
- Ship vNext of the product with real proof

Repeat.

The dungeon does not wait for perfect conditions. It starts harvesting with what it has.
